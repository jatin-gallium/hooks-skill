# Building in Public — Founders Database

A curated collection of social media posts aligned with **building in public** and **startup building**. Each post is saved as an individual `.txt` file for easy reuse as templates or idea inspiration.

## What's Included

Posts are filtered for relevance to one or more of these themes:

- **Building in public** — sharing progress, metrics, lessons learned openly
- **Startup building** — launches, pivots, growth tactics, fundraising stories
- **Founder journey** — mindset, failures, wins, day-in-the-life narratives
- **Product development** — shipping, MVPs, iterations, user feedback loops
- **Revenue & traction** — MRR, ARR, user milestones, growth numbers

## Directory Structure

```
building-in-public-founders-database/
├── README.md
└── posts/
    ├── 001-descriptive-title.txt
    ├── 002-descriptive-title.txt
    └── ...
```

## How to Use

- Browse the `posts/` folder for inspiration
- Use any post as a template — adapt the structure, tone, or hook for your own content
- Each file is a standalone post, ready to remix
