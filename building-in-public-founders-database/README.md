# Building in Public — Founders Database

A curated collection of social media posts aligned with **building in public** and **startup building**. Organized for efficient AI agent consumption: scan the index first, then read only the category you need.

## Source

[Sky Yang's LinkedIn](https://www.linkedin.com/in/skyyang/recent-activity/all/) — 152 posts exported, **81 curated** into this database.

## How to Use (for AI Agents)

1. **Read `INDEX.md` first** — compact table with one row per post (hook, tags, category, template type). Low token cost.
2. **Open only the category file you need** — each post is separated by `---` and labeled `### #NNN`.
3. Tags and template types help you find the right post without reading everything.

## Filtering Criteria

Posts were included if they related to:
- Building in public (sharing progress, metrics, lessons learned)
- Startup building (launches, pivots, growth tactics, fundraising)
- Founder journey (mindset, failures, wins)
- Product development (shipping, MVPs, iterations, user feedback)
- Revenue & traction updates (MRR, ARR, milestones)

Posts excluded: event-only promos, duplicate posts, personal/cultural content without startup lessons, short thank-yous, hiring ads, pre-startup content, gibberish.
