# Brief — Listicle / Split List Post

Use for "N things that…", "N mistakes…", "N wins + N losses" posts. Saves-and-reshares engine.

## Pre-fills

- **Best formats**: Dense (for single-line list-promise hooks), Punchy+Context (list promise + tension line), Stacked sub-variants B/D (for parallel or jargon-stacked hooks).
- **Angle bias**: Odd numbers beat even. The negative / "wins AND losses" split beats wins-only. The failure-first list beats success-only.
- **Rules to emphasize**: Rule 28 (failure-first list), Rule 29 (split list — positives + negatives), Rule 2 (specific N).
- **Register**: Standard or lowercase; match author voice.

## Brief

```
BRIEF: listicle

## Raw material

- The N (odd numbers beat even): <<...>>
- The unit being listed (mistakes, tools, habits, channels, plays): <<...>>
- If split list: N things I like / M things I don't:
  - Like: <<N + what>>
  - Don't like: <<M + what>>
- If failure-first list: <<N that didn't help + M that did>>
- One representative item from the list (shows tone & specificity):
  <<...>>
- Who the list is for (exclude deliberately): <<...>>

## Audience

- Primary audience: <<B2B | founder | marketer | creator>>
- Niche: <<#tag>>

## Author voice

- Register: <<standard | lowercase>>
- Voice notes:
  <<...>>

## Format bias

- Prefer: <<Dense | Punchy+Context | Stacked-B | Stacked-D>>
- Avoid: Single-Line Bomb — no room for the list-promise.
- Media attached: <<none | carousel>>

## Rules to emphasize

Rule 2 (specific N), Rule 28 (failure-first list), Rule 29 (split list with negative count),
Rule 40 (stacked jargon cut-off if audience is expert).

## Constraints

- Do NOT promise a round number ("10 tips"). Odd beats even (3, 5, 7, 9).
- Do NOT use "ultimate" / "definitive" / "complete guide" — AI-cliché signal.
- No em dashes.

## Output request

Generate 8–10 hooks. At least 1 Rule 28 failure-first variant. At least 1 Rule 29 split-list variant.
Recommend top 3.
```

## How to use this brief well

- **Negative counts beat positive counts.** "6 things I like about my CEO. And 3 things I absolutely don't." — the "3 I don't" is what earns the click (Rule 29).
- **Failure before wins.** "9 channels that didn't help us get there… and 5 that did" reads as honest. (Rule 28)
- **One item in the hook tests the whole list.** If the example item is generic, the list will be.
