# Brief — Base (do not use directly; template for all other briefs)

This is the shell every brief extends. It maps 1:1 to the questions SKILL.md asks in the "When the user gives a TOPIC" workflow, plus a format bias.

---

```
BRIEF: <<post-type>>

## Raw material (must fill all, none "n/a" unless truly absent)

- Surprising result / specific number / thing I almost didn't include:
  <<...>>

- Before/after OR belief that changed OR thing that went wrong before it worked:
  <<...>>

- Scene / specific moment / dialogue / setting I can anchor on:
  <<...>>

- Contrarian claim I can defend (if any):
  <<...>>

- Named villain, metric, artifact, stakes:
  <<...>>

## Audience

- Primary audience: <<B2B | personal-brand | mixed>>
- Niche: <<#tag>>
- What the reader is probably worried about right now:
  <<...>>

## Author voice

- Register: <<standard | lowercase>>  (lowercase only if author is consistently casual)
- Author credential(s) I can lean on (keep factual):
  <<...>>

## Format bias (optional — skill will choose if unset)

- Prefer: <<Dense | Punchy+Context | Single-Line Bomb | Stacked | any>>
- Avoid: <<list or "none">>
- Media attached: <<none | image | video | chart-or-graph | carousel>>

## Rules to emphasize (optional)

<<e.g. "Rule 2 specific numbers, Rule 20 contrarian, Rule 37 cliffhanger">>

## Constraints

- Do NOT include: <<...>>
- Hard facts / numbers to preserve:
  <<...>>
- Banned phrases beyond SKILL.md default list: <<none | list>>

## Output request

Generate 8–10 hooks per SKILL.md output format. Recommend top 3.
```

---

## How to use this well

- **Fill every section.** Empty sections turn into vague hooks.
- **If you can't fill "Surprising result" or "Scene I can anchor on," you don't have a post yet.** Go find one piece of specific raw material first.
- **Register is the silent killer.** Standard caps in a casual creator's feed reads stiff; lowercase in a B2B feed reads careless. Pick once, stick with it.
- **`Rules to emphasize` is for when you already know the angle.** E.g. "This is a contrarian data post — emphasize Rule 2 and Rule 20."
- **`Media attached`** changes which formats fit best (see SKILL.md "Media and Hook Strategy"). Chart/graph → Stacked sub-variant C. Strong image → short Bomb or Punchy+Context.
