# Brief — Data / Framework / Research Post

Use when you have a surprising number, a research finding, or a named framework.

## Pre-fills

- **Best formats**: Dense (when claim needs context), Punchy+Context (when number stands alone), Stacked sub-variant C (if chart attached).
- **Angle bias**: Lead with the number or the reframe. Never lead with the methodology.
- **Rules to emphasize**: Rule 2 (specific numbers), Rule 20 (contrarian when applicable), Rule 26 (credential + constraint for authority).
- **Register**: Usually `standard`. Lowercase only if the author's brand is consistently casual.

## Brief

```
BRIEF: data-framework

## Raw material

- The number that matters most (be specific — "$47,312" beats "~$50k"):
  <<...>>

- The reframe or contrarian takeaway the number supports:
  <<...>>

- Methodology in one sentence (do NOT lead with this):
  <<...>>

- The source of authority (credential, client base, dataset size):
  <<...>>

- Audience pain the finding speaks to:
  <<...>>

## Audience

- Primary audience: B2B | personal-brand | mixed: <<...>>
- Niche: <<#tag>>
- Diagnostic question the reader is asking: <<"Does this apply to me?">>

## Author voice

- Register: <<standard>>
- Author credential(s):
  <<...>>

## Format bias

- Prefer: <<Dense or Punchy+Context>>
- Avoid: Stacked sub-variant B (parallel regret) — mismatched for data.
- Media attached: <<none | chart-or-graph | carousel>>

## Rules to emphasize

Rule 2 (specific numbers), Rule 20 (counterintuitive claim), Rule 26 (authority + filter).
If a chart is attached: Rule 43 (Data-Question Opener, Format 4C).

## Constraints

- Do NOT fabricate numbers.
- Do NOT lead with "In today's fast-paced world…" or "I've been thinking about…".
- Facts to preserve verbatim:
  <<...>>

## Output request

Generate 8–10 hooks. At least 2 Dense, at least 2 Punchy+Context.
If chart attached, include 1 Stacked-4C. Recommend top 3.
```

## How to use this brief well

- **Pick the number FIRST.** Everything else in the hook serves the number.
- **If the finding is obvious, don't post it.** Data hooks fail when the takeaway is "study confirms thing you already believed."
- **Chart attached?** → Format 4C is the only format where a question mark is allowed. Use it.
- **No chart?** → Prefer Dense so the number gets full oxygen.
