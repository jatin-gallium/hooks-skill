# Pattern templates

One file per hook pattern family (`<pattern-slug>.md`). Use [`_base-hook.md`](./_base-hook.md) as the shell.

Templates are populated / refined as swipes using that pattern accumulate. Swipe counts under "Swipes using this pattern" are auto-appended during intake.

See [`../../references/02-hook-taxonomy.md`](../../references/02-hook-taxonomy.md) for the list of pattern families.
