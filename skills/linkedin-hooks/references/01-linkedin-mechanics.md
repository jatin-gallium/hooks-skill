# 01 — LinkedIn Mechanics

STATUS: draft (numbers are directional; will be tightened from user swipes)

Understanding the surface before picking a pattern.

## The feed surface — what the reader actually sees

Before expansion, a reader sees roughly:

```
[Creator name]
[Title / one-line bio]
[Time posted] · [Visibility]

[HOOK — about 2-3 lines of text]
...see more
```

If there's media, the hook shares space with it. Text-only posts give the hook the most room.

## The "...see more" cutoff

- Desktop: ~210 characters or ~3 lines, whichever comes first.
- Mobile: ~140 characters or ~2 lines.
- **Always write assuming mobile**. Most consumption is mobile.
- A single line break inside the first 140 chars can push critical content below the fold. Design the first ~140 chars as the hook proper.

## What LinkedIn's feed seems to reward (directional)

- **Dwell time** on the post after expansion. Long posts that get read win.
- **Early engagement** (comments > likes > reshares). First 60-90 min matters most.
- **Comments with substance** (length, replies) > quick emoji reactions.
- **Saves** (quiet signal, but strong).
- **Profile clicks + follows** (strong signal the post did work).
- **Dwell without engagement** is still positive; keep them reading even if they don't comment.

Things that seem to **hurt** reach:

- Outbound links in the post body (consider first-comment link).
- Editing the post heavily in the first hour.
- Too many hashtags (>3–5 feels noisy; 0–3 is fine).
- Generic engagement bait ("agree?"); algorithm seems to have learned to discount shallow comments.

## Timing (directional, not gospel)

- Weekday mornings in the audience's timezone generally outperform.
- Tuesday–Thursday > Monday/Friday for B2B.
- Posting consistency > posting perfectly — the feed rewards creators it recognizes.

## Post length bands

| Band     | Chars       | Typical use                                  |
| -------- | ----------- | -------------------------------------------- |
| Short    | <500        | Punchy take, one-liner framework, contrarian |
| Medium   | 500–1200    | Listicle, mini-story, teardown               |
| Long     | 1200–3000   | Storytime, deep case study, framework drop   |
| Max-long | 3000+       | Rare; only if every line earns its place     |

LinkedIn post hard cap is ~3000 characters. Going long only pays off if dwell time goes up, which means **every line must earn the next line**.

## Format mechanics that matter

- **Short lines.** Single-sentence "lines" are the norm. Visual whitespace = perceived readability.
- **No wall of text.** Break every 1–2 sentences.
- **Bullet-style lists** (with `—` or `•` or no bullet, just line breaks) work great for listicles.
- **Emojis**: 0–2 per post is safe; used as visual anchors, not decoration.
- **No links in the body** if you care about reach — put them in the first comment and reference them.
