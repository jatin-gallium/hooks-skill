# 99 — Review Checklist

STATUS: draft

Run this checklist before posting. Every `[ ]` should be `[x]` or consciously skipped.

## Hook (first 1–3 lines)

- [ ] Self-contained — a cold reader understands the tension.
- [ ] Uses a named pattern from `02-hook-taxonomy.md`.
- [ ] Under ~140 characters in the first line (mobile cutoff).
- [ ] Opens a curiosity loop or stakes — doesn't give away the payoff.
- [ ] No LinkedIn-voice filler ("In today's fast-paced world…").
- [ ] No quote on the very first line.

## Body (framework)

- [ ] Uses a named framework from `03-story-frameworks.md`.
- [ ] One idea — not two or three.
- [ ] One sentence per line (mostly); whitespace between beats.
- [ ] Specific nouns, verbs, numbers — no vague advice.
- [ ] Every line earns the next line. Cut the ones that don't.
- [ ] Hook's promise is paid off in the body.

## CTA

- [ ] One CTA (not stacked).
- [ ] Matches the post goal (reach / list / DM / save / share).
- [ ] On its own line, near the end.
- [ ] Not "Thoughts?" / "Agree?"
- [ ] The post earns the CTA asked for.

## Voice & format

- [ ] Sounds like the creator, not like LinkedIn.
- [ ] 0–2 emojis, used as anchors.
- [ ] 0–3 focused hashtags (or none).
- [ ] Previewed on mobile.
- [ ] No outbound link in the body (move to first comment if needed).

## Niche adaptation (if remixing)

- [ ] Actor, stakes, metric, jargon, artifact, villain are niche-specific.
- [ ] Voice register matches the niche.
- [ ] Not a line-for-line copy of the source swipe.

## Database hygiene

- [ ] If this post performs, it will be ingested as a swipe (creator = self).
- [ ] If this post borrows from a swipe, that swipe is linked in the creator's personal notes.
