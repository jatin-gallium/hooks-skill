# 03 — Story Frameworks

STATUS: draft

The framework is the **shape of the full post**. The hook earns the expansion; the framework earns the read-through.

Every swipe gets tagged with 1 primary framework (sometimes + 1 secondary when they're blended).

## The frameworks we track

### `pas` — Problem, Agitate, Solve

- **Shape**:
  1. Name the problem the reader has.
  2. Twist the knife (make the pain vivid).
  3. Offer the solution / framework.
- **Best for**: pain-aware audiences; persuasion; lead gen.
- **Hook patterns it pairs with**: `stakes-or-warning`, `list-of-mistakes`, `contrarian-claim`.

### `bab` — Before, After, Bridge

- **Shape**:
  1. Describe the "before" state (painful).
  2. Describe the "after" state (aspirational).
  3. Bridge = the method that gets them from A to B.
- **Best for**: transformation stories, case studies, how-to.
- **Pairs with**: `before-after`, `how-i-did-it`, `stat-drop`.

### `aida` — Attention, Interest, Desire, Action

- **Shape**:
  1. Attention = the hook.
  2. Interest = relevant story/context.
  3. Desire = benefit / outcome to the reader.
  4. Action = CTA.
- **Best for**: promotional posts; launches.
- **Pairs with**: `curiosity-gap`, `bold-declaration`.

### `storytime` — Narrative arc

- **Shape**:
  1. Cold-open scene (specific time/place/tension).
  2. Stakes / what was on the line.
  3. Complication / turn.
  4. Resolution.
  5. Portable lesson for the reader.
- **Best for**: personal brand; memorable lessons; virality.
- **Pairs with**: `storytime-cold-open`, `personal-confession`, `specific-moment`.

### `listicle` — Enumerated list

- **Shape**:
  1. Hook that promises N items.
  2. The N items, each 1–3 lines, each useful on its own.
  3. Optional wrap-up line or CTA.
- **Best for**: saves, shares, evergreen value.
- **Pairs with**: `list-promise`, `list-of-mistakes`, `insider-reveal`.

### `contrarian-take` — Thesis + Defense

- **Shape**:
  1. State the contrarian claim.
  2. Name the mainstream view you're rejecting.
  3. Give 2–4 reasons / evidence points.
  4. Land with the reframe.
- **Best for**: thought leadership; comment-bait (in a good way).
- **Pairs with**: `contrarian-claim`, `one-weird-reframe`, `us-vs-them`.

### `case-study` — Receipts

- **Shape**:
  1. Who / what / outcome (up top, concrete numbers).
  2. The context/constraints.
  3. The moves, step by step.
  4. What generalizes for the reader.
- **Best for**: credibility-building; B2B; lead gen.
- **Pairs with**: `stat-drop`, `how-i-did-it`, `authority-drop`.

### `framework-drop` — Teach a model

- **Shape**:
  1. Name the framework (gives it a handle).
  2. Why it matters / what it replaces.
  3. The steps / components.
  4. Example or use case.
- **Best for**: saves, reshares, positioning as an expert.
- **Pairs with**: `one-weird-reframe`, `insider-reveal`, `authority-drop`.

### `teardown` — Analyze a public artifact

- **Shape**:
  1. Name the artifact (ad, post, landing page, launch).
  2. The result / context.
  3. What they did well / wrong.
  4. The generalizable lesson.
- **Best for**: expertise demo; comments from people with opinions.
- **Pairs with**: `insider-reveal`, `contrarian-claim`.

### `mini-manifesto` — Short punch post

- **Shape**:
  1. Bold one-line thesis.
  2. 3–5 short affirming/expanding lines.
  3. Close with the thesis or a mirror of it.
- **Best for**: identity content; shareability; short-form.
- **Pairs with**: `bold-declaration`, `pattern-interrupt`.

### `q-and-a` — Question led

- **Shape**:
  1. Ask the question the reader is asking.
  2. Give the honest answer (often unexpected).
  3. Unpack with 2–3 supporting points.
- **Best for**: SEO-like discovery on LinkedIn; demonstrating thinking.
- **Pairs with**: `question-hook`, `insider-reveal`.

### `timeline-receipts` — Dated beats

- **Shape**:
  1. Anchor with a date/time span.
  2. Walk through the milestones (Day 1 / Week 2 / Month 6).
  3. End with the meta-lesson.
- **Best for**: founder journey; transformation; "how I built this."
- **Pairs with**: `specific-moment`, `how-i-did-it`, `stat-drop`.

## Framework picking — quick decision

- Have a specific win with numbers? → `case-study` or `bab`.
- Have a spicy opinion? → `contrarian-take`.
- Have a painful lesson? → `storytime` or `pas`.
- Have evergreen tactical value? → `listicle` or `framework-drop`.
- Promoting something? → `aida`.
- Have a short punchy take? → `mini-manifesto`.
- Teaching a model? → `framework-drop`.
- Analyzing something public? → `teardown`.
- Answering an FAQ in the niche? → `q-and-a`.
- Showing a journey? → `timeline-receipts`.
