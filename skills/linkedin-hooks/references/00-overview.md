## What is a "hook" on LinkedIn?

A **hook** is the first 1–3 lines of a LinkedIn post — the part visible in the feed before the "...see more" cutoff. Its only job is to earn the click/expansion. Nothing else. Not to inform, not to sell, not to teach. Earn. The. Expansion.

Once the expansion happens, the **body** (story framework) takes over and does the actual job: teach, persuade, entertain, prove, CTA.

## The three layers of any great LinkedIn post

1. **Hook** — earns expansion (uses a hook *pattern*).
2. **Story framework** — earns read-through (uses a *framework* like PAS, BAB, storytime, listicle).
3. **Close + CTA** — earns engagement (comment / save / DM / follow).

If any layer is weak, the post under-performs — no matter how good the other two are.

## Vocabulary

| Term               | Meaning                                                                 |
| ------------------ | ----------------------------------------------------------------------- |
| Hook               | First 1–3 lines; everything above "...see more".                        |
| Pattern            | The *mechanism* a hook uses (curiosity gap, contrarian, stat, etc.).    |
| Framework          | The *shape* of the full post (PAS, BAB, AIDA, storytime, listicle...).  |
| Swipe              | A real post from another creator, stored in the database as reference.  |
| Remix              | Taking a swipe and adapting it to a new niche / angle / voice.          |
| Niche-agnostic     | A template written without a specific niche; placeholders to fill in.   |
| Engagement signal  | Rough proxy for "this worked" — likes, comments, reshares, saves, views.|
| "See more" cutoff  | The character count at which LinkedIn truncates the post in feed.       |
| Dwell time         | How long readers spend on the post after expanding — huge ranking input.|

## Three rules that never change

1. **The first line is everything.** If it doesn't earn the click, the rest doesn't exist.
2. **One idea per post.** Two good ideas in one post = one mediocre post.
3. **Write for the scroller, not the reader.** Your reader is scrolling at 60mph. You have ~1 second.
