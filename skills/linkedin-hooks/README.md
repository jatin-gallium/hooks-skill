## Drop format (how to hand me posts)

See [`references/INTAKE.md`](./references/INTAKE.md). Short version:

- Paste raw post text. That's enough.
- Optionally add: creator name, rough engagement signal (e.g. "top 1%", "5k likes"), niche of origin.
- Drop them one at a time OR in bulk, separated by `---`.
