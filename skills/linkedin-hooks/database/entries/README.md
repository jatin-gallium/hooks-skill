# Atomic knowledge entries

One file per non-swipe fact/rule/quote/observation you want searchable.

Filename: `YYYYMMDD-slug.md`. Include YAML front-matter with `tags:` so entries show up under the right search.

Example front-matter:

```yaml
---
date: 2026-04-17
source: <optional: creator / book / thread>
tags: [#rule, #hook, #niche-saas]
---
```

Body: one clear paragraph or a short list. Keep each entry atomic.
